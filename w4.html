연결 설정

클로드 앱 안에서 열면 설정 없이 바로 대화가 됩니다.
이 파일을 따로 열어 쓰려면 본인의 Anthropic API 키를 한 번 넣어 두세요(이 기기에만 저장).




키 만들기 — console.anthropic.com 가입 → 결제 등록 → API Keys에서 발급 → 월 한도(Limits)를 1~2만원으로 꼭 설정.

마이크 — 다운로드 파일(content:// 주소)에선 음성 인식이 규격상 막힙니다. 입력창을 누르고 키보드의 마이크로 말하면 사실상 음성 입력입니다. 완전한 마이크는 https 주소로 열 때만 됩니다.

안내

무엇인가 — 실제 고민을 함께 풀면서 판단력을 키우는 코치입니다. 답을 대신 주지 않고 질문으로 당신이 스스로 좋은 판단에 이르게 이끕니다. 상담이 쌓일수록 살핌·읽기·묻기·묵히기 네 힘이 자랍니다. 살핌은 보는 데서 그치지 않고 방향을 트는 것까지입니다. 진단·치료가 아닙니다. (카드 0718A 기준)

쓰는 법 — 가운데 단추를 누르고 말하면 됩니다. 답은 소리로도 읽어 줍니다. 상담이 마무리되면 「정리」를 누르세요 — 사례 카드 한 장이 남고, 오늘 자란 힘이 기록됩니다. 「기록」을 열면 네 힘의 성장 막대가 보이고, 다음에 오시면 지난 결정의 복기부터 이어집니다.

조망 주의 — 시선은 귀 옆 공간에, 눈동자를 똑바로 길게 보지 않기. 야간·과다반복·이중거울은 역효과.
